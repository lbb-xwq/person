9 年 前端开发

把复杂界面做成能长期维护的系统

九年里一直在做企业级前端：中后台系统、数据可视化大屏、组件体系与工程化建设。习惯从 0 到 1 搭架构，也习惯回头把老项目的构建和性能问题一个个收拾干净。

  • 01 / VUE 生态

    Vue 生态

    用 Vue 3 + TypeScript 做中后台系统：动态路由实现不同权限的校验与菜单匹配，Pinia 管全局状态并持久化，Element-Plus 做业务组件。

    • 0x00 Vue 3
    • 0x01 TypeScript
    • 0x02 Pinia
    • 0x03 Vue Router
    • 0x04 Element-Plus

  • 02 / REACT 生态

    React 生态

    React 单页应用开发，用 redux / react-thunk / redux-actions 处理状态，用 HOC 抽离可复用的组件逻辑。

    • 0x00 React
    • 0x01 Redux
    • 0x02 HOC
    • 0x03 Ant Design
    • 0x04 React-Bootstrap

  • 03 / 数据可视化

    数据可视化

    ECharts 与 ECharts-GL 组合出 2D/3D 图表，通过缩放方案统一大屏自适应；地图与告警类模块用 OpenLayers + GeoServer 对接设备数据。

    • 0x00 ECharts
    • 0x01 ECharts-GL
    • 0x02 OpenLayers
    • 0x03 GeoServer
    • 0x04 大屏自适应

  • 04 / 工程化与构建

    工程化与构建

    能从 0 到 1 独立搭建项目架构；Vite / webpack / vue-cli 全流程都熟，做过 webpack 3 升 4、按路由代码分包、依赖与体积治理。

    • 0x00 Vite
    • 0x01 Webpack
    • 0x02 代码分包
    • 0x03 打包提速
    • 0x04 0-1 架构

  • 05 / 组件与复用

    组件与复用

    表格与表单的二次封装、用 hooks 抽离列表页通用逻辑、用自定义指令解决大数据量下拉卡顿，让同类页面能快速开发。

    • 0x00 表格/表单二次封装
    • 0x01 Hooks
    • 0x02 自定义指令
    • 0x03 Element-UI
    • 0x04 Vant

  • 06 / 微前端与集成

    微前端与集成

    按子系统成熟度选择 micro-app 或 iframe 两种方式内嵌其他项目，统一登录态（OAuth）与消息通道，支持模块独立部署与集成。

    • 0x00 micro-app
    • 0x01 iframe
    • 0x02 OAuth
    • 0x03 独立部署
